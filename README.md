## 一、总则

### （一）编制目的

为便于用户在中文界面环境下切换 Apex Legends 的配音语言，避免因切换语言而反复下载、卸载语音包，特编制本说明书。

### （二）适用范围

1. 本工具适用于 Steam 版 Apex Legends，操作系统为 Windows 10 / 11。
2. EA App 版本未经实测，不在本说明书覆盖范围内。
3. 本工具为非官方社区工具，与 Electronic Arts、Respawn Entertainment 无隶属或合作关系。

### （三）术语说明

1. **配音**：游戏内角色语音所使用的语言，独立于界面语言。
2. **语音包**：游戏目录下 `audio\ship\general_<语言>.mstr` 文件，多个语言包可共存。
3. **启动项**：Steam 为游戏设置的启动参数，位置为「属性 → 通用 → 启动选项」。
4. **备份库**：本工具用于存放语音包副本的本地目录。

## 二、功能与原理

### （一）主要功能

1. **切换配音**：写入配音配置，写入前自动备份原文件。
2. **带配音启动**：以所选配音参数直接启动游戏，即时生效。
3. **语音包备份**：将已下载的语音包复制至本地备份库，供日后恢复。
4. **恢复默认**：清除配音设置，使配音跟随界面语言。
5. **自动检测**：自动定位游戏目录与配置文件。

### （二）技术原理

1. 配音语言由 `+miles_language <语言>` 启动参数控制，与界面语言解耦。
2. 语言在游戏启动时读取，**切换后须重启游戏方可生效**。
3. 经实测，仅将 `miles_language` 写入 `profile.cfg`（旧教程做法）在当前版本不一定被读取——当前版本将设置存于 `local\settings.cfg`。故本工具主推「启动游戏」方式，将参数直接交由 Steam 启动器传递给游戏，即时生效。
4. 本工具同时将 `miles_language` 写入 `profile.cfg` 与 `local\settings.cfg` 作为辅助（写入前均自动备份），但**以启动参数为准**。

### （三）安全说明

1. 本工具仅修改本地配置文件与 Steam 启动项，**不注入游戏进程、不读取游戏内存、不修改游戏本体文件、不接触反作弊系统**。
2. 所使用的机制为游戏自带的语音切换功能，社区长期实践未见封号案例。
3. 该用法无官方背书，使用风险由用户自行评估承担。

## 三、获取与启动

### （一）运行环境

1. 操作系统：Windows 10 / 11（64 位）。
2. 依赖：已安装 Steam 版 Apex Legends。
3. 无需安装 Python，无需命令行环境。

### （二）获取方式

1. 从 [Releases](https://github.com/BEIMINGruoxi/apex-voice-switcher/releases/latest) 下载 `ApexVoiceSwitcher-v<版本号>.exe`。
2. 单文件程序，可放置于任意目录，无需安装。

### （三）首次启动

1. 双击 `Apex语音切换器.exe`。
2. 如遇 Windows「已保护你的电脑」提示，依次选择「更多信息」→「仍要运行」。
3. 程序自动识别游戏目录与配置文件；若路径为空，点击「自动检测」或手动选择。

## 四、界面说明

### （一）界面布局

界面自上而下分为三个无标题圆角分区：

```
╭──────────────────────────────────────────╮
│ 游戏目录    [__________] [浏览] [自动检测] │
│ profile.cfg [__________] [浏览] [ /刷新  ] │
│ 备份库      [__________] [浏览]            │
╰──────────────────────────────────────────╯
╭──────────────────────────────────────────╮
│ 当前配音：日语 ●        启动项：日语（一致）│
│ 语言              | 语音包状态             │
│ [切换配音] [启动游戏] [备份语音包]         │
│ [恢复默认] [使用指南]                      │
╰──────────────────────────────────────────╯
╭──────────────────────────────────────────╮
│ 操作日志（常显）                           │
╰──────────────────────────────────────────╯
                              作者：北冥若曦 v1.12.0
```

### （二）分区说明

1. **第一分区（路径设置）**：设置游戏目录、配置文件路径与备份库目录。
2. **第二分区（状态与操作）**：显示当前配音与 Steam 启动项状态，提供全部功能按钮。
3. **第三分区（操作日志）**：常显区域，记录全部操作，供排查问题使用。

### （三）界面规范

1. 三个分区不带标题文字，以圆角边框区分；圆角半径随系统缩放自适应。
2. 配色采用 Apple 系统色板：浅灰窗底 `#f5f5f7`、纯白卡片、系统蓝主色 `#007AFF`、系统绿 / 红状态色。
3. 按钮为胶囊形自绘控件：主要操作为蓝底白字，次要操作为浅灰底；按下即变色，禁用态自动弱化。
4. 窗口高度贴合内容，默认约 540 px；纵向拉伸时多余空间分配给日志区，语言列表尺寸不变。
5. 语言列表固定 8 行高度，语言数量超过 8 种时出现滚动条。
6. 状态行颜色含义：
   - 绿色：与当前设置一致；
   - 红色：不一致，从 Steam 库启动将使用启动项语言；
   - 灰色：启动项未固定。
7. 打开二级窗口时，主窗口自动锁定（不可拖动、不可点击），关闭后立即恢复。
8. 程序已声明 DPI 感知并按系统缩放渲染，在 4K / 150% 缩放下文字与控件清晰。
9. 进程与 Steam 状态检测均调用 Windows 系统 API，不弹出控制台窗口。
10. 图标以 base64 内嵌于源码，窗口、任务栏、快捷方式共用同一图标，exe 单独移动不会丢失图标。

## 五、操作说明

### （一）切换配音

1. 在语言列表中选中目标语言。
2. 点击「切换配音」。
3. 程序执行两步：
   - 第一步：写入配音配置，写入前自动备份原文件；
   - 第二步：检测 Steam 状态。Steam 已完全退出则自动写入启动项，不弹窗口；Steam 仍在运行则弹出引导窗口，退出 Steam 后写入按钮自动解锁。
4. 点击「稍后再说」不影响第一步结果。

### （二）带配音启动

1. 在语言列表中选中目标语言。
2. 点击「启动游戏」。

参数直接交给游戏进程，不依赖 Steam 启动项，不受游戏更新影响，为最可靠的使用方式。

### （三）语音包备份

1. 点击「备份语音包」。
2. 在弹窗中勾选需要备份的语言，默认全选。
3. 程序在后台复制至备份库；已存在且大小相同的文件自动跳过。

### （四）恢复默认

1. 点击「恢复默认」。
2. 程序删除配置文件中的 `miles_language` 行，配音随界面语言变化。

### （五）新语言包获取

每个语言只需操作一次：

1. 完全退出 Apex。
2. 打开 Steam → 右键 Apex → 属性 → 语言，改为目标语言，等待下载完成。
3. 打开本工具，点击「备份语音包」，勾选该语言并备份。
4. 将 Steam 语言改回简体中文。
5. 此后该语言可随时切换；若语音包被 Steam 清理，「切换配音」会自动从备份库恢复。

> 注意：第二步通常需下载十余 GB，请预留时间与磁盘空间。

## 七、配置说明

### （一）配置文件位置

1. 程序配置：`%APPDATA%\ApexVoiceSwitcher\config.json`，首次运行自动生成。
2. 游戏配置：`profile.cfg`，位于 `Saved Games\Respawn\Apex\profile\`。

### （二）备份文件

每次写入游戏配置前，自动生成 `profile.cfg.bak.apexvoice`。如需还原，将该文件改名为 `profile.cfg` 即可。

### （三）只读属性

部分环境下 `profile.cfg` 带只读属性。程序会自动临时解除只读、写入完成后恢复原属性，无需手动处理。

> 提示：只读属性同样会导致游戏内画面、按键设置无法保存。如需游戏正常保存设置，可在文件属性中取消「只读」。

## 八、常见问题处理

### （一）切换配音后游戏内无变化

**现象**：已完成切换，但进入游戏仍为原配音。

**处理**：
1. 确认已完全退出游戏后重新启动。
2. 使用本工具「启动游戏」按钮启动（最可靠）。
3. 如习惯双击桌面图标启动，须先通过「切换配音」写入 Steam 启动项。

### （二）顶部提示「与当前设置不一致」

**现象**：界面顶部显示红色提示。

**处理**：该提示为状态报告，非报错。表示 Steam 启动项固定的是另一种语言。
1. 选中目标语言，点击「切换配音」。
2. 在弹窗中先退出 Steam，再点击「立即写入」。
3. 状态变绿即为一致。

### （三）备份提示「新复制 0 个」

**现象**：备份操作完成，但未复制任何文件。

**处理**：
1. 检查「游戏目录」是否指向包含 `audio\ship` 的层级。
2. 可填写根目录、`audio` 或 `audio\ship`，三者均支持。
3. 或点击「自动检测」重新定位。

### （四）启动游戏报音频文件加载失败

**现象**：启动时提示音频文件缺失。

**处理**：
1. 打开 Steam → 属性 → 已安装文件 → 验证文件完整性。
2. 或从本工具备份库中恢复对应语言包。

### （五）进游戏报 CSOM 错误

**现象**：提示 `CSOM_MilesAsync_openOrFindFile ... failed to open`。

**处理**：语音包版本落后于游戏版本。
1. 点击「恢复默认」后进入游戏。
2. 按第五章第（五）节重新下载该语言包并备份。

### （六）配置存在空值 miles_language

**现象**：工具提示配置中存在 `miles_language ""`。

**处理**：该空值会导致游戏无法加载语音包。执行「切换配音」或「恢复默认」任一操作即可修复。

### （七）游戏更新后语言包消失

**现象**：游戏更新或验证文件后，某语言配音失效。

**处理**：Steam 会按清单清理不在列表内的语音包。此前已备份的，点击「切换配音」自动恢复，无需重新下载。

### （八）需要还原原始配置

**处理**：将 `profile.cfg.bak.apexvoice` 改名为 `profile.cfg`。

## 九、源码构建与版本发布

### （一）构建

环境要求：Python 3.12 及以上、PyInstaller。

```bash
pip install pyinstaller
pyinstaller "Apex语音切换器.spec" --noconfirm
```

构建产物位于 `dist\Apex语音切换器.exe`。图标与版本资源随仓库提供，无需额外准备。

### （二）版本发布

```bash
python scripts/release.py patch -m "本次改动说明"
```

脚本同步更新源码 `APP_VERSION`、`version_info.txt` 与本文档中的版本号，随后提交、打 `vX.Y.Z` 标签并推送。标签推送后，GitHub Actions 自动在 Windows 环境构建 exe 并创建 Release。

版本规则：

| 类型 | 适用情形 | 示例 |
| --- | --- | --- |
| `patch` | 缺陷修复、文案调整 | 1.12.0 → 1.12.1 |
| `minor` | 新增功能，向后兼容 | 1.12.0 → 1.13.0 |
| `major` | 不兼容变更 | 1.12.0 → 2.0.0 |

### （三）目录结构

```
apex_voice_switcher.py     主程序（单文件）
Apex语音切换器.spec         PyInstaller 打包配置
version_info.txt            exe 版本资源（作者 / 版权 / 版本号）
app_icon.ico                应用图标（7 档尺寸）
_verify_mark.py             防伪标记二进制校验工具
scripts/release.py          版本发布脚本
docs/                       使用教程（Markdown 与 Word 版）
```
