- 三个分区**不带标题文字**，用圆角边框区分；圆角半径随系统缩放自适应（150% 缩放下为 15px）。
- **视觉风格（Apple 设计语言）**：
  - 配色采用 Apple 系统色板——浅灰窗底（`#f5f5f7`）+ 纯白卡片 + 系统蓝主色（`#007AFF`）+ 系统绿/红状态色；

  - **按下即反馈**：按钮在鼠标按下的瞬间变色（Apple 交互原则），悬停有轻微明暗变化，禁用态自动降低存在感；
  - 排版分光学层级：标签用次级灰（`#86868B`）、内容用主黑（`#1D1D1F`），输入框聚焦时边框变蓝；
  - 语言列表平坦化：无网格线、行高更舒适、选中浅蓝、「当前配音」行浅绿、缺失语言弱化灰；
  - **克制动效**：启动时窗口 180ms 淡入（ease-out）；若 Windows「显示动画」被关闭（减弱动效偏好），淡入自动跳过。
- **窗口高度贴合内容**：默认约 540px 高（不再固定 1020px）；把窗口拖高时，多出的空间给 ③ 日志区，语言列表尺寸不变。
- **语言列表固定 8 行高度**：不论装了几种语言都保持 8 行高度（视觉稳定、不跳动），超过 8 种语言时用滚动条查看。
- **② 区状态行**：左侧是「当前配音」，右侧是「Steam 启动项」状态——绿色＝与当前设置一致；红色＝不一致（从 Steam 库启动会用启动项的语言，详细说明会自动写入 ③ 日志一次）；灰色＝启动项未固定。
- 打开二级窗口（「备份语音包」「切换配音」弹出的窗口）时，**主窗口会被自动锁定**——不能拖动、不能点击，避免误操作；二级窗口关闭后立即恢复。
- 窗口标题栏不显示作者名；作者署名以**小字号浅灰色**放在右下角，防伪强度由 exe 文件属性与源码署名保证（右键 exe → 属性 → 详细信息可见）。
- **自定义图标**：窗口左上角、任务栏、桌面快捷方式均使用同一张图标（源图 `app_icon.ico` / 7 档尺寸 16→256）。图标以 **base64 内嵌在源码里**，所以 exe 单独拷到任何地方都不会掉图标。

## 原理（重要：配音靠启动参数生效）

- 配音语言由 **`+miles_language <语言>` 启动参数**控制，与界面语言解耦；**语言在游戏启动时读取，切换后必须重启游戏**。
- ⚠️ 实测结论：把 `miles_language` 写进 `profile.cfg`（老教程的做法）在当前版本**不一定被读取**——当前版本 Apex 把设置写在 `local\settings.cfg`。因此本工具**主推「启动游戏（带所选配音）」按钮**：它把这行参数直接交给 Steam 启动器传给游戏，即时生效、不用改 Steam 启动项、不用重启 Steam、也不受游戏更新影响。
- 工具同时会把 `miles_language` 写进 `profile.cfg` 与 `local\settings.cfg` 作为辅助（写入前均自动备份），但**以启动参数为准**。
- 语音包是 `Apex Legends\audio\ship\general_<语言>.mstr`，**多个语言包可共存**，游戏只加载被指定的那个。
- 社区长期实践无封号案例（官方原始文件 + 官方参数机制），但请理解此类用法无官方背书。

## 快速开始

1. **双击 `Apex语音切换器.exe`**（无需安装、无需 BAT、无需 Python）。
2. 首次运行如遇「已保护你的电脑」提示，「更多信息」→「仍要运行」即可。
3. 工具自动识别游戏目录与 profile.cfg；若为空点「自动检测」或手动选择。
4. **在列表中选中想要的配音语言 → 点「切换配音（并引导写入启动项）」**：
   - 第一步自动完成配音切换（写入配置，写入前自动备份）；
   - 第二步自动判断 Steam 状态：**Steam 已完全退出 → 自动写入启动项，不弹任何窗口**；**Steam 仍在运行 → 才弹出引导窗口**（窗口会自动监听 Steam 状态，你退出 Steam 后写入按钮自动解锁；点「稍后再说」也不影响第一步的结果）。
5. 不想动 Steam 时，直接点 **「启动游戏（带所选配音）」**——参数直接交给游戏，即时生效。

> 建议：日常就用「启动游戏（带所选配音）」；希望从 Steam 库直接启动也带配音时，再走一次第 4 步的第二步。

## 功能按钮说明

| 按钮 | 位置 | 作用 |
|---|---|---|
| **切换配音** | 主按钮区 | 一键两步：①写入配音配置（原文件自动备份）→ ②Steam 已退出则自动写入启动项（不弹窗），Steam 仍运行才弹窗引导 |
| 启动游戏 | 主按钮区 | 启动 Apex 并附带 `+miles_language <所选语言>`，即时生效、不用动 Steam |
| 备份语音包 | 主按钮区 | 弹出勾选界面，选择要备份的语言（默认全选），后台复制到备份库；已存在且大小相同的文件自动跳过 |
| 恢复默认 | 主按钮区 | 删除配置文件中的 miles_language 行，配音跟随界面语言 |
| 使用指南 | 主按钮区 | 弹出「配音切换说明」窗口：分步卡片式引导（步骤徽章、浅蓝重点提示、状态颜色图例、常见问题），给别人用也能一眼看懂 |
| 自动检测 / 刷新 | 右上角 | 二合一按钮：路径缺失或失效时自动定位并回填（**不会覆盖你手填的有效路径**），随后刷新全部状态 |

> **游戏目录填写方式**：填 Apex 根目录、`...\audio`、`...\audio\ship` 三种任意一种都能正确识别（程序会自动归一化）。
> **高分屏**：程序已声明 DPI 感知并按系统缩放渲染，在 4K / 150% 缩放下字体与控件清晰、不模糊。
> **无黑窗闪烁**：进程/Steam 状态检测走 Windows 系统 API（不调用命令行工具），全程不会弹出黑色控制台窗口；Steam 状态轮询也在后台静默进行。

## 首次获取新语言包（每个语言只需下载一次）

1. 完全退出 Apex；
2. Steam → 右键 Apex → 属性 → 语言 → 改为目标语言，等待语音包下载完成；
3. 回到本工具点 **「备份语音包…」**，勾选该语言后备份；
4. Steam 语言改回简体中文；
5. 若包被 Steam 删除，之后在工具里「切换配音」会自动从备份库恢复。

## 常见问题

- **界面顶部提示「Steam 启动项已固定为 …」/「…与当前设置不一致」**
  这是工具在报告 Steam 启动项与当前配音设置的关系，不是报错（该提示**每 0.5 秒自动刷新**，你在 Steam 里改了启动项或切换配音后会立刻更新）：
  - 绿色 **✔ 与当前设置一致** = 正常状态（从 Steam 库启动也会用该配音）；
  - 红色 **⚠ 不一致** = 启动项里固定的是另一种语言，从 Steam 库启动时会以启动项为准。要统一：选中目标语言 → 点「切换配音（并引导写入启动项）」→ 在弹窗中先退出 Steam 再点「立即写入」。
- **切换了配音但游戏里没变化**
  配音语言只在**游戏启动时**读取：请关闭游戏，用工具点「启动游戏（带所选配音）」按钮启动（这是最可靠的方式）；单纯写配置文件在部分版本上不生效。
- **启动游戏时游戏报错 / 提示音频文件加载失败**
  通常是所选语言（或界面语言对应的语言）语音包不在游戏目录里。打开 Steam 属性→已安装文件→验证完整性，或用本工具从备份库恢复；Steam 语言对应的语音包缺失时，验证文件会自动补下。
- **备份时提示「新复制 0 个」**
  说明在游戏目录下没扫到语音包。检查「游戏目录」是否指向含 `audio\ship` 的那一层（填根目录 / `audio` / `audio\ship` 都支持）；工具在扫不到文件时会在日志里直接给出提示，也可点「自动检测」。
- **工具提示「配置存在空值 miles_language ""」**
  配置文件里有一行 `miles_language ""`（历史遗留），空值会让游戏加载不到语音包。点「切换配音」（写入有效语言）或「恢复默认」（删除该行）任一操作即可修复。
- **profile.cfg 是只读属性怎么办**
  部分机器上该文件带「只读」属性（游戏自身也因此无法把设置写回）。工具会自动临时解除只读、写入完成后再恢复原属性，无需手动处理。
  注意：只读属性会让**游戏内的画面/按键等设置无法保存**；如需让游戏正常保存设置，可在文件右键→属性中取消勾选「只读」。
- **进游戏报 `CSOM_MilesAsync_openOrFindFile ... failed to open`**
  语音包版本落后于游戏版本（大更新后可能出现）。先「恢复默认」进游戏，等有空时按上面流程重新下载一次该语言包并重新备份。
- **切换不生效**
  检查 Steam 启动项（属性 → 通用 → 启动选项）里是否有旧的 `+miles_language ...`，有则删除（工具也会在顶部红色警告提示）。
- **游戏更新后日语包消失**
  Steam 校验/切换语言会按清单清理，从备份库「切换配音」即可自动恢复，无需重新下载。
- **恢复配置**
  每次写配置前都会生成 `profile.cfg.bak.apexvoice`，出问题把它改名回 `profile.cfg` 即可。

## 从源码构建

需要 Python 3.12 及以上与 PyInstaller：

```bash
pip install pyinstaller
pyinstaller "Apex语音切换器.spec" --noconfirm
```

产物位于 `dist\Apex语音切换器.exe`。图标与版本资源随仓库提供，无需额外准备。

## 发布新版本

仓库内置语义化版本发布脚本，一次同步源码 `APP_VERSION`、`version_info.txt` 与 README 中的版本号：

```bash
python scripts/release.py patch -m "本次改动说明"
```

脚本会自动提交、打 `vX.Y.Z` 标签并推送。标签推送后，GitHub Actions 在 Windows 环境自动构建 exe 并创建 Release。

版本规则：`patch` 修缺陷、`minor` 加功能、`major` 不兼容变更。
